# QR actuales · OYL 3.4

Abrir QR_TODOS.png para mostrar la hoja completa. Los PNG individuales pueden imprimirse o mostrarse desde otro monitor. codigos.csv contiene los contenidos exactos.

Instalar la APK nueva. Los QR usan oyl://product/ID. Un lector externo debe admitir apertura de URI personalizados para entrar a OYL; algunas cámaras sólo abren HTTPS y necesitan App Links con dominio propio. Ver ESCANER_QR_3_4.md.

No usar los antiguos OYL:ID para apertura externa. Se siguen aceptando dentro de OYL. El ID 999999 comprueba el caso inexistente; el código ajeno debe rechazarse. Productos se consultan siempre en la base local del teléfono.
